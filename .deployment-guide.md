# Deployment Guide untuk aaPanel

## Langkah-langkah Deploy Production

### 1. Build Production
```bash
npm run build
```

### 2. Pilih Metode Deploy

#### Opsi A: Menggunakan PM2 (Recommended)
```bash
# Install PM2 globally (jika belum)
npm install -g pm2

# Start aplikasi
npm run pm2:start

# Atau langsung:
pm2 start ecosystem.config.cjs

# Lihat logs
pm2 logs dracin

# Restart
pm2 restart dracin

# Stop
pm2 stop dracin

# Setup auto-start saat server reboot
pm2 startup
pm2 save
```

#### Opsi B: Menggunakan Node langsung
```bash
# Jalankan production server
npm run prod

# Atau langsung:
node ./dist/server/entry.mjs
```

#### Opsi C: Menggunakan Preview (untuk testing)
```bash
npm run preview
```

### 3. Setup Reverse Proxy di aaPanel

1. Buka aaPanel → Website → domain Anda
2. Klik "Reverse Proxy"
3. Setup:
   - **Target URL**: `http://127.0.0.1:4321`
   - **Enable WebSocket**: OFF (karena production tidak butuh HMR)
   - **Cache**: Optional

### 4. Environment Variables (Optional)

Buat file `.env` di root project jika perlu:
```env
NODE_ENV=production
HOST=0.0.0.0
PORT=4321
```

## Troubleshooting

### Error: WebSocket connection failed
**Penyebab**: Menjalankan `npm run dev` di production
**Solusi**: Gunakan `npm run build` + `npm run pm2:start`

### Error: Port already in use
```bash
# Cek process yang pakai port 4321
lsof -i :4321

# Kill process
kill -9 <PID>

# Atau ganti port di ecosystem.config.cjs
```

### Video tidak bisa play
1. Cek CORS di browser console
2. Pastikan server bisa akses internet (untuk fetch API provider)
3. Cek firewall aaPanel

## Monitoring

```bash
# PM2 monitoring
pm2 monit

# Logs
pm2 logs dracin --lines 100

# Status
pm2 status
```

## Update Aplikasi

```bash
# 1. Pull latest code
git pull

# 2. Install dependencies (jika ada perubahan)
npm install

# 3. Build ulang
npm run build

# 4. Restart
pm2 restart dracin
```
