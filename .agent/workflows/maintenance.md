---
description: Cara Mengaktifkan Mode Maintenance
---
Untuk mengaktifkan atau menonaktifkan mode maintenance:

1. Login ke panel admin di `/admin/login`.
2. Buka **Admin Dashboard**.
3. Scroll ke bawah hingga menemukan section **Sistem Maintenance**.
4. Centang **Status Maintenance** untuk mengaktifkan.
5. Isi **Pesan Maintenance** dan **Perkiraan Kembali** (misal: "1 jam lagi").
6. Klik **Simpan Konfigurasi Maintenance**.

**Catatan:** Admin tetap bisa mengakses dashboard `/admin` meskipun mode maintenance sedang aktif, sehingga Anda bisa mematikan mode maintenance kapan saja.
